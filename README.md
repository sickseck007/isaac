# Isaac Guess Club

Фан-сайт для игры «Угадай предмет» из **The Binding of Isaac: Repentance**. Две страницы: личные поля друзей и рулетка со скрываемым результатом. Игра работает в одном браузере без регистрации и сервера.

## Что умеет

- 718 коллекционных предметов Repentance с локальными пиксельными иконками, русскими и английскими названиями в поиске, качеством и типом.
- От 1 до 8 игроков: настраиваемые имена, отдельные исключения и секретный предмет у каждого.
- Поле из 1–100 предметов, выбор набора из каталога, фильтры по качеству/типу и настройка количества столбцов.
- Нажатие переворачивает карточку; повторное нажатие возвращает её. Поиск, просмотр оставшихся, сброс и отмена последнего действия.
- Рулетка со случайным равновероятным выбором из всего каталога или текущего поля. Нажатие на результат скрывает и сам предмет, и его изображение в рулетке.
- Автоматическое сохранение игры в `localStorage`, адаптивный интерфейс, управление с клавиатуры и поддержка уменьшенной анимации.

## Как играть

1. Настройте друзей и набор предметов. У всех одинаковые карточки, но свой прогресс.
2. Каждый игрок выбирает себя, переходит в рулетку и выбирает **«С игрового поля»**, если секрет нужно угадывать по карточкам. Для игры с полным каталогом оставьте **«Все предметы»**.
3. Крутите рулетку, запоминайте результат и скрывайте его нажатием.
4. Задавайте вопросы с ответом «да» или «нет» и исключайте неподходящие карточки на своём поле.
5. Назовите предмет и проверьте догадку, открыв секрет друга.

Прогресс хранится только в текущем браузере. Комнат и синхронизации между устройствами нет. Скрытие защищает от случайного взгляда, а не от человека, имеющего доступ к инструментам разработчика или локальному сохранению.

## Разработка

Нужен Node.js 24 (либо совместимый Node.js 22.12+).

```sh
npm ci
npm run dev
```

Для сборки и проверок:

```sh
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют системный `/usr/bin/chromium`, если он установлен. На другой машине сначала установите Chromium командой `npx playwright install --with-deps chromium`. Playwright сам запустит сервер разработки на порту 4173. Для проверки сборки используйте `npm run preview`.

## Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`: установка по lockfile, тесты, сборка и публикация `dist`.

1. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. В **Actions → Deploy Isaac Guess Club** запустите **Run workflow**. Последующие push в `main` запускают публикацию автоматически.
3. Ссылка на работающий сайт появится в **Settings → Pages** и результате deployment. До успешного deployment наличие кода в GitHub не означает, что сайт опубликован.

`base: './'` поддерживает путь проекта `/isaac/`. Изображения и шрифты включены в сборку; внешние CDN при открытии сайта не требуются.

## Иконки и источники

Все 718 иконок уже лежат в `public/items/`; дополнительно скачивать их не нужно. Каталог — в `src/data/items.json`, происхождение и контрольные суммы — в `public/items/manifest.json`, подробные источники и атрибуция — в [public/items/SOURCES.md](public/items/SOURCES.md).

Использованы исходные пиксельные спрайты из IsaacWallpaper и Isaac Codex, данные каталога Isaac Codex/Platinum God и русские названия External Item Descriptions. Брелоки, карты, пилюли, дополнения Repentance+ и внутренние альтернативные состояния не включены. Изображения принадлежат правообладателям игры; проект не связан с Edmund McMillen или Nicalis.
