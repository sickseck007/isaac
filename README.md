# Isaac Guess Club

Фан-сайт для игры «Угадай предмет» из **The Binding of Isaac: Repentance**. Три страницы: личные поля друзей, рулетка со скрываемым результатом и справочник Dead God. Игра работает в одном браузере без регистрации и сервера.

## Что умеет

- 718 коллекционных предметов Repentance с локальными пиксельными иконками, русскими и английскими названиями в поиске, качеством и типом.
- От 1 до 8 игроков: настраиваемые имена, отдельные исключения и секретный предмет у каждого. По умолчанию все поля видны рядом; переключатель «Все поля / По одному» меняет вид без сброса прогресса. На телефоне поля располагаются друг под другом.
- Поле из 1–718 предметов: ручной набор, фильтры по качеству, типу, пулу и тегам, отдельные пулы Greed mode.
- Пресеты «Случайный микс», «Только легенды», «Нажми пробел» и «Маленькая армия», равномерный подбор разных качеств и перенос точного поля через код `IGC1:`.
- Настройки из Dead God: группировка по категории, коллекции, пулу, превращению, достижению или качеству; сортировка, язык названий, сетка/список, ID и качество, семь цветов поля. Исключённые карточки можно переворачивать, затемнять или скрывать.
- Кнопка ⓘ открывает эффекты, синергии, баги, условия открытия и остальные сведения из предоставленного HTML. Ссылки на другие записи внутри описаний открывают их в том же окне.
- Справочник из 1 185 записей: 719 предметов, 188 брелоков, 97 карт/рун, 50 пилюль, 17 превращений, 40 пикапов и 74 объекта окружения. Broken Glass Cannon показан в справочнике как альтернативное состояние, но не участвует в игре.
- Нажатие переворачивает карточку; повторное нажатие возвращает её. Поиск, просмотр оставшихся, сброс и отмена последнего действия.
- Рулетка со случайным равновероятным выбором из всего каталога или текущего поля. Нажатие на результат скрывает и сам предмет, и его изображение в рулетке.
- Автоматическое сохранение игры в `localStorage`, адаптивный интерфейс, управление с клавиатуры и поддержка уменьшенной анимации.

## Как играть

1. Настройте друзей и набор предметов. У всех одинаковые карточки, но свой прогресс. Играйте на полях рядом или включите «По одному» для большого поля. В виде со всеми полями кнопка кубика у имени открывает рулетку нужного игрока.
2. Каждый игрок выбирает себя, переходит в рулетку и выбирает **«С игрового поля»**, если секрет нужно угадывать по карточкам. Для игры с полным каталогом оставьте **«Все предметы»**.
3. Крутите рулетку, запоминайте результат и скрывайте его нажатием.
4. Задавайте вопросы с ответом «да» или «нет» и исключайте неподходящие карточки на своём поле.
5. Назовите предмет и проверьте догадку, открыв секрет друга.

Прогресс хранится только в текущем браузере. Комнат и синхронизации между устройствами нет. Скрытие защищает от случайного взгляда, а не от человека, имеющего доступ к инструментам разработчика или локальному сохранению.

## Разработка

Нужен Node.js 24 (либо совместимый Node.js 22.12+).

```sh
npm ci
npm run dev
```

Для сборки и проверок:

```sh
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют системный `/usr/bin/chromium`, если он установлен. На другой машине сначала установите Chromium командой `npx playwright install --with-deps chromium`. Playwright сам запустит сервер разработки на порту 4173. Для проверки сборки используйте `npm run preview`.

## Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`: установка по lockfile, тесты, сборка и публикация `dist`.

1. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. В **Actions → Deploy Isaac Guess Club** запустите **Run workflow**. Последующие push в `main` запускают публикацию автоматически.
3. Ссылка на работающий сайт появится в **Settings → Pages** и результате deployment. До успешного deployment наличие кода в GitHub не означает, что сайт опубликован.

`base: './'` поддерживает путь проекта `/isaac/`. Изображения и шрифты включены в сборку; внешние CDN при открытии сайта не требуются.

## Повторный импорт Dead God

Владелец dead-god.ru предоставил сохранённую главную страницу. Импорт извлекает все её `.item-data` записи и настройки, не выполняя скрипты страницы:

```sh
npm run import:dead-god -- '/путь/к/сохранённой странице.html'
```

Результаты:

- `public/data/descriptions/` — отдельные описания всех 1 185 записей; браузер загружает описание при открытии.
- `public/data/dead-god-all.json` — полный экспорт исходных полей, включая текст и HTML, доступный для скачивания из справочника.
- `public/data/dead-god-settings.json` — пулы, теги и настройки исходной страницы.
- `public/data/dead-god-provenance.json` — SHA-256 входного файла, время импорта, количество записей и проверка внутренних ссылок.
- `src/data/referenceIndex.json` — индекс справочника; `src/data/items.json` — коллекционные предметы для игры с метаданными Dead God.

Это снимок данных предоставленного HTML, включая встречающиеся в нём изменения Repentance+. Игровой набор остаётся набором Repentance; русский перевод и качество взяты из снимка Dead God. Отдельные страницы `/stats`, `/about`, история изменений и сопровождающая папка сохранённых ресурсов не были приложены и не восстановлены. Одна недоступная иллюстрация делений заряда отображается текстом. Внешний код WordPress, счётчики и скрипты исходного сайта не включены в приложение.

## Иконки и источники

Все 718 игровых иконок уже лежат в `public/items/`; дополнительно скачивать их не нужно. В `public/reference-icons/` добавлены 187 иконок брелоков и Broken Glass Cannon; у остальных записей без доступного спрайта показан символ категории. Каталог — в `src/data/items.json`, происхождение и контрольные суммы — в `public/items/manifest.json`, подробные источники и атрибуция — в [public/items/SOURCES.md](public/items/SOURCES.md).

Использованы исходные пиксельные спрайты из IsaacWallpaper и Isaac Codex. Базовые игровые ID и типы проверены по IsaacScript и Isaac Codex/Platinum God; описания и метаданные импортированы из HTML Dead God, предоставленного владельцем. Брелоки, карты и пилюли доступны в справочнике. Изображения принадлежат правообладателям игры; проект не связан с Edmund McMillen или Nicalis.
